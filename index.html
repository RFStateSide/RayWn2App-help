Welcome to RayWn2App Help

Welcome to RayWn2App, your WN-2 station display and operating companion. Watch forward and reflected power, check SWR, arrange meters to suit your station, and keep records of your operating sessions. You can start with a ready-made layout and use the program without designing a dashboard. When you are ready, change the arrangement, add instruments and save different layouts for different activities.

Start here

  1. Install and open RayWn2App.
  2. Connect your WN-2.
  3. Check Device Settings, including the coupler fitted to each channel.
  4. Choose a layout and start reading your meters.


A radio-and-amplifier layout connected to a physical WN-2. RF is idle in this example. Select image to enlarge.

Find your way around

The main menu guide explains where to find each tool. The Layout Edit Mode walkthrough takes you through creating your own display. Instruments explains which meter to choose, including the cross-needle meter. RF couplers are factory calibrated and do not require additional calibration for normal operation. Select the correct coupler model for each channel. Optional user reference matching is available if you want the displayed power to agree with another meter you have chosen.
