Installing and opening RayWn2App

On this page

  • Install RayWn2App
  • Open the application
  • If installation or startup fails
  • Updates and another computer

Install RayWn2App

Use the installation package supplied with your WN-2 or obtained from RF StateSide. Choose the package for your computer and follow its instructions. The installer, or the supplied Linux installation script, installs the components needed to run RayWn2App. You do not need to install programming tools. Keep the installation instructions with the package in case you need to move to another computer.

Choose your operating system

  • Windows installation and USB connection
  • Ubuntu Linux installation and USB connection
  • Raspberry Pi installation and USB connection
  • macOS installation and USB connection

Each page includes a real connected WN-2 example and explains the driver choices for that computer.

Open the application

On Windows, open RayWn2App from the Start menu or its shortcut. On Linux or Raspberry Pi, use the application launcher created during installation. On macOS, open the installed application from Applications. Connect the WN-2 by USB and follow First station connection. If the operating system asks for permission to use a microphone while you are recording messages, allow it only if you intend to record.

If installation or startup fails

Run the supplied installer or setup script again and follow its repair instructions. Make sure you used the package for your operating system and computer. If the problem continues, contact RF StateSide with the error message and your operating-system version. Do not change coupler calibration to resolve an installation problem.

Updates and another computer

Keep copies of your saved layouts and recorded messages before updating. When moving to another computer, copy those files and select the correct WN-2 identity in your instruments. Audio devices and saved passwords may need to be selected or entered again. A layout file does not contain passwords or device calibration preferences. See Connection problems if the program opens but cannot find your WN-2.
