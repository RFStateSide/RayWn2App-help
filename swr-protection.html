SWR protection, trips and manual reset

On this page

  • Set protection for the intended device
  • When a trip occurs
  • Manual reset
  • Optional automatic reset

Set protection for the intended device

Open Device → SWR Protection. Select the WN-2 identity, check the supported command interpretation, choose the protection channel(s) and set the SWR limit. Use the interpretation appropriate to your WN-2; older hardware may support one selected channel rather than a channel combination. Save preferences keeps your choices. Apply to device sends the selected protection settings. Read the status afterward. The last successfully applied compatible settings are restored on a later connection; merely saving a new draft does not make it the applied setting.


SWR Protection identifies the device, requested settings and reported trip state. Select image to enlarge.

When a trip occurs

A dedicated SWR Trip warning identifies the affected WN-2, regardless of which instruments are visible. Stop transmitting and address the cause before resetting. Resetting may restore an amplifier keying path connected through the relay. The warning is based on the WN-2's reported trip state. Unknown or disconnected is not the same as not tripped. Repeated reports of the same trip do not create a new dialog for every reading.

Manual reset

With the cause addressed and RF off, use Reset SWR Relay in the warning or protection window. Wait for the application to report that fresh WN-2 information shows not tripped. Sending the command alone is not confirmation of the relay state or its physical contacts. Dismiss warning closes the dialog without changing the relay. A new trip can reopen it. Use SWR warnings in the status area to return to warnings.

Optional automatic reset

Smart Reset adds an optional RF-off waiting policy. It is OFF by default and is separate from the hardware trip threshold. Do not enable it without understanding what the relay controls in your station.
