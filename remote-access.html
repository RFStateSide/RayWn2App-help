Remote Station — Host and Clients

Use Remote Station to watch your WN-2 measurements from another computer running RayWn2App. The computer beside the WN-2 is the host or server. It owns the USB connection. A client is another copy of RayWn2App that receives the host's readings and displays them in its own layout. Several clients can watch the permitted meters at the same time.

Example 1 — Your home radio station

Keep the WN-2 connected to your station computer. Start the desktop Station Host there. At another computer in the house, open Remote Client and pair it with that host. When travelling, use your station's VPN to reach the host. Your client layout can show CH2 forward and reflected power, SWR, DC readings or temperature while your station computer continues monitoring.

Start with Set up the desktop Station Host. Once it is listening, follow Pair a Remote Client.

Example 2 — An unattended repeater site

A Raspberry Pi stays at the site with one or more WN-2 meters attached. Its Station Host service starts at boot and records measurements even when nobody is watching. An operator pairs a client over the site's LAN or VPN to see measurements and export retained history. A second operator can pair another client with its own dashboard and permitted devices.

Set up the service first using Unattended Station Host on Raspberry Pi. Then follow Pair a Remote Client and Browse and export station history.

First-time setup order

  1. Choose the host computer and prepare its certificate and private key.
  2. Connect the WN-2 on the host and check its local readings. Configure and start the desktop host or Pi service.
  3. Verify that the host is listening. Create a pairing code for the devices that client may see.
  4. Enter the host address, verified fingerprint and code on the client. Bind the client instruments to the remote device.

What you can monitor

Remote clients display RF, DC, auxiliary inputs, temperatures and SWR protection status. The Pi service also provides recorded CSV history. Hardware controls and capture tools operate locally on the station host. Station protection and USB recovery continue there independently of client connectivity.

Use a LAN or VPN address that the client can reach. The address 127.0.0.1 refers to the computer on which you enter it. Use it when both copies run on that computer or when a configured SSH tunnel forwards the connection. For an ordinary connection between two computers, enter the host's LAN or VPN address.

For direct access by monitoring software, see the optional read-only HTTPS / JSON API.
