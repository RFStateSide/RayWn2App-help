Compact Station Panel and enlarged meters

Compact Station Panel

Choose Tools → Compact Station Panel. Select the WN-2, check the channels you want to show, and choose Horizontal or Vertical. Set Columns to arrange the selected channels across the panel. Use it beside your logging or radio-control software. On top keeps it above other windows. Hide main reduces the space occupied by the main dashboard; use the panel's return/show control to bring it back. The panel remembers its size and position when reopened.


Compact Station Panel connected to the selected WN-2. Select image to enlarge.

Enlarge one instrument

Right-click a dashboard meter and choose Enlarge in separate window. Drag the window border to make the instrument easy to read. A horizontal bar normally needs a wide, shallow window; an analog meter benefits from more height.


A wide, shallow detached bar display, without unused space below it. Select image to enlarge.


An analog meter enlarged to make the face prominent. Select image to enlarge.

Click Return to dashboard, or close the detached window, to put the instrument back. Its original dashboard space is kept for it. It remains the same instrument with the same source and settings.

Which should I use?

Use the Compact Station Panel for several channels in a separate small window. Use detached enlargement when one particular meter needs a larger view. Neither requires a separate WN-2 connection.
