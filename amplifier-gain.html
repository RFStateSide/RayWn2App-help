System and Module Gain instruments

On this page

  • Connect the measurements
  • Add or configure Gain
  • System and module gain
  • Watch changes over time

Connect the measurements

Use one RF coupler before the amplifier and another after it. In the supplied amplifier layout, CH1 is the input and CH2 the output. Select the actual models in Device Settings.

Add or configure Gain

Choose Amplifier Gain as the instrument Measurement. Select the WN-2, Amp In RF Channel and Amp Out RF Channel. Use different channels with the correct physical roles. Give the instrument a useful label. Choose Gain units as dB or Power ratio (×). For example, an output ten times the input is 10×, or 10 dB. Switching units changes the presentation, not the underlying measurements.

System and module gain

System Gain compares the measured output with the measured input. If using Module Gain with an input attenuator allowance, enter the appropriate attenuation in Properties. Do not add an allowance unless it represents your actual arrangement. The Low RF threshold applies to the output channel only. A positive input below its own Low RF threshold can still be used for gain. Zero or negative input, stale/disconnected readings, clipped ADC data and invalid readings remain unavailable; gain is never calculated by dividing by zero. The readings are not guaranteed to describe precisely the same instant, so compare stable operating conditions where practical.

Watch changes over time

Use Tools → RF History and Amplifier Analysis to compare input/output trends. The application does not adjust transmitter drive. You remain responsible for the station's operating limits.
