RayWn2App on Raspberry Pi

Start with the installation package supplied with your WN-2 or downloaded from RF StateSide. Keep the instructions supplied with that package: its exact filename and setup prompts may differ between releases.

Choose the Pi package

Use a supported 64-bit Raspberry Pi OS desktop and the ARM64 RayWn2App package. The connected illustration was made on a Raspberry Pi 5. An Intel/AMD Linux package or an ARMv7 package is not interchangeable with ARM64.

  1. Extract the complete package. Follow its included instructions; if it contains install.sh, open a terminal in the extracted folder and run sh ./install.sh.
  2. Allow the installer to finish the WN-2 USB-access and desktop dependency setup. Complete any requested sign-out or restart.
  3. Start RayWn2App from the desktop application launcher as your normal user.

Connect the physical WN-2

Use a reliable Pi power supply and a USB data cable. Power the WN-2, press Discover, select its serial number and VCP, then Connect. The illustration uses VCP. Its port may appear as /dev/ttyUSB0; the serial number remains the useful device identity.

D2XX is available with the ARM64 driver and the WN-2-specific USB setup. As on Ubuntu, disconnect first and use the supplied USB-mode helper, if included, to release VCP before choosing D2XX. Never attempt both connections to the same meter at once. See Linux D2XX selection.

Audio, shortcuts and screen size

Choose an actual HDMI, USB or other available audio output before using spoken readings, tones or messages. Dummy Output means there is no usable playback route; successful installation alone does not make sound available. Recording also needs a microphone. On Wayland desktops, global audio shortcuts may be unavailable; the on-screen message buttons remain available.

For a small screen, choose fewer instruments, use the Compact Station Panel or adjust application scaling. Layout files can be shared with other computers; check their WN-2 bindings after loading. Keep adequate free storage for recordings and history exports.

Check your first readings

The status bar should show your meter Live and its link healthy. Load a supplied layout and bind its instruments to that same WN-2. With the transmitter in receive, near-zero power, Low RF and unavailable SWR are normal. They do not mean that the USB connection failed.

RF couplers are factory calibrated and do not require additional calibration. Optional user reference matching is available if you want readings to match another meter. See First station connection, Device Settings and Connection problems.
