Power, SWR and Return Loss

Power readings

Forward average is the average power flowing toward the load. Reflected average is average power returning from it. The corresponding peak readings show higher short-term power levels and are useful with speech or changing signals. Choose the reading that suits your operating activity. A peak-hold display may retain a previous high value; look for Held/Live indications. Peak hold explains how to reset it.

SWR and Return Loss

SWR indicates the relationship between forward and reflected power. A value close to 1:1 means little reflected power relative to forward power. Return Loss presents related information in dB; a higher return loss means less reflection. When forward power is too low, SWR can be unavailable even though the connection is healthy. Do not interpret an unavailable reading as a perfect match.

Measurement processing

Open Device → Settings → RF couplers, select the WN-2 and channel, then choose Measurement processing. Eligible new configurations for all nine current WaveNode models start with WaveNode-compatible (recommended): WaveNode host factory power conversion, Corrected detector average and Paired-peak SWR. These are host-calculation defaults, not a claim that every meter or firmware revision has been physically qualified.

  • WaveNode-compatible (recommended) selects all three methods together. Factory conversion bypasses saved scalar coefficients while selected, but never overwrites them. Saved ADC zero offsets remain in use. Active reference matching retains precedence.
  • Legacy RayWn2App restores the saved scalar conversion, unweighted average and average-power-ratio SWR.
  • Custom / Advanced identifies a mixture of policies. The three individual controls remain available below the preset and show the actual selections.

Upgrading from v0.0.2: previously saved channels keep their effective choices, coefficients, zero offsets and reference curves. Missing policy settings in an existing profile retain the earlier behavior; nominal-looking saved coefficients cannot prove that no user calibration was performed. Choose the recommended preset explicitly if you want to compare the newer calculations. Switching back to Legacy restores the stored scalar-profile results. Choices are remembered for each WN-2, channel and coupler model.

HF-8KW factory conversion is available, including the host's channel-specific detector response. Only 20KW parity is deferred; saved 8KW and custom calibration remain intact. See the nine-model table for direct-source versus approved rated-range mappings. Processing-policy choices alone send no hardware command or detects firmware capabilities.

Choosing the SWR calculation

Open Device → Settings → RF couplers, select the device and Channel 1–4, then choose SWR calculation. Paired-peak SWR is the default for eligible new supported configurations. Legacy (average-power ratio) preserves previously saved results, including when the average-power estimate is enabled.

Paired-peak SWR calculates SWR and Return Loss from the calibrated forward and reflected peak readings reported together in a meter data frame. It keeps up to three recent pairs for one second and, with three available, uses the pair having the middle reflected/forward ratio. With one or two pairs it uses the newest pair. This reduces isolated ratio spikes and never mixes forward and reflected maxima from different frames. It does not use the display’s peak hold. It is a RayWn2App calculation, not a reproduction of WaveNode’s original SWR processing; comparison with reference instruments on real signals remains to be qualified.

The selection is remembered separately for each device, channel and coupler model. No calibration values are changed and no command is sent to the WN-2. Hardware SWR protection continues to operate independently. History is cleared on disconnect, stale or invalid readings and relevant profile changes. No SWR is provided for low RF, clipping, invalid input or an expired pair. An unavailable reading is not a safe-load indication.

The numeric SWR in digital, Combined RF Channel and cross-needle instruments follows this selection. Cross-needle power needles continue to show average watts; with Paired-peak selected their intersection can differ from the numeric SWR, and the dial identifies that distinction. Logging and telemetry receive the same selected calculation. The optional average-power estimate and all reported peak/held-peak displays remain separate.

Check the source before comparing

Each instrument has a Device identity and RF channel. Check its label, channel and coupler selection if the reading is unexpected. Forward and reflected readings come from the existing WN-2 measurements; different average and peak readings need not describe the same instant.

Calibration

RF couplers are factory calibrated and do not require further calibration for normal use. The selected coupler model must match the connected coupler. Optional user reference matching changes the application's displayed power to agree with a chosen reference; it does not recalibrate the coupler itself.

Host-compatible coupler power conversion

Open Device → Settings → RF couplers → Channel 1–4 → RF power conversion. WaveNode host factory is selected by the recommended preset for eligible new configurations. Legacy (saved calibration) preserves existing readings and calibration. The factory mode uses an independently implemented factory detector model for the LP-1, standard HF and HF-8KW families. It includes level-dependent detector correction and reflected-peak compensation. It can change both average and reported peak watts.

Calibration compatibility: while factory mode is selected, stored scalar coefficients are bypassed, not overwritten or reinterpreted. Your saved ADC zero offsets remain in use. If user reference matching is enabled, the whole channel keeps its existing conversion instead, so your reference curve and the other direction remain unchanged. To compare the factory model, you can turn off Use user reference matching without deleting its points. Select Legacy to restore scalar-profile results. This is an explicit choice for each device, channel and coupler model; saved profiles are never automatically migrated.

The existing Average-power calculation choice remains independent. With the factory mode it chooses unweighted or crest-weighted compensated detector averages. Weighting is applied once before conversion to watts. Legacy power conversion retains its existing average estimate unchanged. Both SWR choices use the selected calibrated power model; Legacy SWR keeps its pre-weighting average basis, while Paired-peak uses corresponding calibrated peaks. Neither hardware SWR protection nor software peak hold is changed.

This mode matches the original host's per-frame conversion, not its adjustable history averaging, peak selection or the WN-2 front-panel integer calculation. Front-panel and computer readings can differ. Matching another display does not establish RF accuracy; verify CW, SSB and known loads with a suitable reference. HF-8KW follows the source-established CH1 versus CH2–4 response. Four additional 2,000 W models share the standard HF family by the owner-approved rated-range mapping; this is identified in the model table and measurement metadata. Custom/20KW profiles keep their stored behavior. Firmware versions are not inferred and no command is sent by the processing-policy setting itself. Changing Coupler type authorizes its sensor-family change on Settings OK; see coupler synchronization.
